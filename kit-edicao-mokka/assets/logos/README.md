# logos/

Coloque aqui as suas logos. Esta pasta não vai para os alunos.

- `logo-[marca]-clara.png` e `logo-[marca]-escura.png`, com fundo transparente, mínimo 1000 px de largura.
- Uma versão só com o símbolo, para a vinheta e para o canto do vídeo.

Para a aluna: crie a sua própria pasta `logos/` com a sua marca.
