# assets/

Elementos visuais liberados para usar nos vídeos.

| Pasta | O que tem | Como usar |
|---|---|---|
| `fontes/` | Anton (títulos), Inter (legenda e textos), Caveat (letra de mão nas notas), Great Vibes (cursiva) | Instale no computador (dois cliques no arquivo) ou importe no editor. |
| `icones/` | certo, errado, check, seta, cadeado, cursor, pessoa | PNG com fundo transparente: arraste para a linha do tempo. SVG para editar cor e tamanho. |
| `overlays/` | fita amarela, fita com nome da aluna, nota adesiva, pílula de legenda, carimbo MITO, etiqueta de nome, botão Saiba mais, cartão riscado, guia de área segura 9:16 | PNG por cima do vídeo. Troque o texto no SVG (abre no Figma, Canva ou navegador). |
| `logos/` | vazia: coloque aqui as suas logos | PNG com fundo transparente, versão clara e escura. |

## Cores usadas
| Cor | Hex | Uso |
|---|---|---|
| Dourado Mokka | `#D2A536` | detalhes, @perfil, cadeado |
| Laranja | `#E8792B` | palavra-chave, fitas, botões |
| Amarelo fita | `#F5C842` | fita adesiva |
| Preto | `#0B0B0B` | pílulas e fundos |
| Creme | `#F6F2EA` | fundos claros |
| Certo / errado | `#2FB86A` / `#E04848` | selos |

O dourado e o preto vêm do painel. O laranja e o amarelo foram tirados dos efeitos. Se a sua marca tiver um hex oficial, troque nos SVGs.

**Guia de área segura:** coloque `overlays/area-segura-9x16.png` por cima do vídeo só na edição para conferir. Tire antes de exportar.
