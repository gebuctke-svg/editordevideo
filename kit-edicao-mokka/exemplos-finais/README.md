# exemplos-finais/

Vídeos inteiros, já publicados, que mostram o resultado esperado de cada receita do Guia 08. A pasta `referencias/` mostra um efeito. Esta mostra o vídeo completo.

**O que entra aqui:** um vídeo final por receita, com o nome no padrão e a capa do lado.
```
erro-comum_final.mp4          erro-comum_capa.png
tres-jeitos_final.mp4         tres-jeitos_capa.png
mito-derrubado_final.mp4      ...
situacao-real_final.mp4
prova-de-aluna_final.mp4
metodo-30s_final.mp4
anuncio-aula_final.mp4
lote-de-ganchos_final.mp4
```

**Como usar:** mande o exemplo final junto com o vídeo bruto e diga "edita na mesma linha deste exemplo". Ou mostre aos alunos antes de pedir a primeira edição.

**Ainda vazia.** Os vídeos finais publicados da Geisy entram aqui. Prova de aluna só com autorização.
